# Embeddings (reductions) available in a scroll project

Embeddings (reductions) available in a scroll project

## Usage

``` r
scroll_embeddings(data, view = NULL)
```

## Arguments

- data:

  A scroll data handle.

- view:

  Optional subset-view name; a subset view returns its (possibly
  partial) embeddings, the whole dataset returns full-coverage
  reductions.

## Value

A character vector of embedding names.
