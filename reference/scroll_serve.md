# Run the scroll explorer locally

Run the scroll explorer locally

## Usage

``` r
scroll_serve(dir = ".", ...)
```

## Arguments

- dir:

  A built scroll project directory.

- ...:

  Passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html) (e.g.
  `port`, `host`, `launch.browser`).
