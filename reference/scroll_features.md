# Features (e.g. genes) of an assay in a scroll project

Features (e.g. genes) of an assay in a scroll project

## Usage

``` r
scroll_features(data, assay = NULL)
```

## Arguments

- data:

  A scroll data handle.

- assay:

  Assay name; `NULL` (default) uses the manifest's default assay.

## Value

A character vector of feature names.
