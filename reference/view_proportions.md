# Stacked composition of one categorical within another

Stacked composition of one categorical within another

## Usage

``` r
view_proportions(cells, params, state = list())
```

## Arguments

- cells:

  The cells data.frame.

- params:

  List with `group_by` (x axis) and `fill_by` (composition).

- state:

  Optional toggle state (`palette`, `normalize`, `legend`).

## Value

A ggplot.

## Deprecated

This plot core is internal to the built-in panels and will no longer be
exported from scroll 0.3.0.
